# ShopSense Portfolio Changes

This edition is tailored to **Bhavyasri Mudireddy — Product Analyst**.

## Major changes

- Rebranded the storefront as ShopSense.
- Added Product Analytics navigation and dashboard modules.
- Added funnel, journey, search, feature-adoption, cohort, experiment, and product-performance views.
- Added comparison and personalized-discovery concepts.
- Added behavioral analytics event vocabulary and PostgreSQL analytics tables.
- Added a lightweight Admin Dashboard for local catalog management.
- Added Product Management with search, view, add, edit, and delete functionality.
- Added category-aware product forms with stock, pricing, image, tags, and merchandising flags.
- Simplified authentication to email/password for a lower-friction local demo.
- Removed Google OAuth dependencies/configuration.
- Removed Stripe/live card payment dependencies/configuration.
- Replaced payment selection with a **Portfolio Demo Checkout** that still creates demo orders.
- Removed saved-payment-card and gift-card account UI.
- Removed original maintainer contact information and old application branding.
- Removed Docker deployment files to keep local portfolio setup focused.
- Rewrote README and Windows run instructions.
- Removed real `.env` files from the distributable package.

# Security Policy

ShopSense is a portfolio and learning project, not a production commerce service.

If you discover a security issue while reviewing or running the project, document it privately and avoid using real credentials, payment details, or sensitive personal data in the demo environment.

## Scope

- Use test/demo data only.
- Keep `.env` files out of source control.
- Do not expose PostgreSQL or the API publicly without adding production-grade security controls.
- No real payment processing is included in this portfolio version.
